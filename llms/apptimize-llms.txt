# Apptimize

> Mobile-first A/B testing, multivariate testing, and feature management platform. Run experiments, ship feature flags with controlled rollouts, deliver instant updates without app-store releases, and set dynamic variables on the fly across iOS, Android, web, and server-side channels. Apptimize was acquired by Airship in 2019; its developer docs and SDKs remain published at apptimize.com/docs.

## APIs
- [Apptimize REST API](https://apptimize.com/docs/apis/rest-api.html): Retrieve variant assignments (code blocks, dynamic variables, feature flags, variant info) and track user events from any device or server. Hosts: https://api.apptimize.com (NA), https://api.apptimize.eu (EU). Auth: ApptimizeApiToken header.
